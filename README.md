# Quentin Fauchereau · Crée ce qui t'anime !

Site de Quentin Fauchereau, accompagnant à Collonges-sous-Salève (Haute-Savoie, aux portes de Genève).
Site statique (HTML, CSS, JavaScript), sans dépendance, prêt pour GitHub Pages, Netlify ou Vercel.

## Les fichiers
| Fichier | Rôle |
|---|---|
| `index.html` | La page principale (accueil, balade, test, offres, qui je suis, FAQ, réservation) |
| `mentions-legales.html`, `confidentialite.html`, `cgv.html` | Pages légales |
| `merci.html` | Page affichée après une réservation Cal.com |
| `assets/js/config.js` | **Les réglages** : lien Cal.com et formulaire du test |
| `assets/js/main.js` | Les animations et le test |
| `assets/css/style.css` | La charte graphique |
| `assets/fonts/` | Polices Poppins et Inter, hébergées sur le site (pas d'appel à Google) |
| `assets/img/` | Logo, icônes, image de partage |
| `A-COMPLETER.md` | **La liste de ce qu'il reste à fournir** |
